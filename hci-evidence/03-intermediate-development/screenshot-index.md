# Screenshot Evidence Index

All assignment evidence is archived outside `public/` so it is not included in the website’s public assets.

## Capture provenance

- **Original website:** Production build of Git commit `dc17fb4`, checked out in a separate worktree before capture.
- **Final website:** Production build from the current working tree, captured locally without deployment.
- **CSS viewports:** Mobile 390 × 844 px; desktop 1440 × 900 px. Full-page capture was enabled, so PNG heights below are the full rendered document heights rather than the viewport heights.
- **Authenticity:** The captures are real browser screenshots. PNGs have not been retouched, reconstructed, or AI-generated. Original/final screenshot widths were checked against the configured viewport widths. The final set has no development overlay.
- **Intermediate archive:** The existing PNG files from `public/hci-redesign/screenshots/` and `public/hci-redesign/edge-test.png` were copied into this folder. They remain unchanged in their original locations. These are phase-specific historical captures; their filenames or content may indicate a previous design state, and some may show a development indicator. Do not treat them as the exact Git-baseline comparison where a file from `01-original-website/` is available.
